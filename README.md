# 🌠 Meteorite Hunter — Predictive Analysis of Global Meteorite Landings  
A machine learning and visualization project using NASA’s Meteorite Landings dataset.  
Predicts meteorite types based on their mass, year, and coordinates, and visualizes their global distribution.

## 🌍 About the Project
Meteorite Hunter aims to make NASA’s meteorite data accessible and insightful.  
Using ML, it predicts the classification of meteorites and visualizes global landing patterns.  
This project supports science education and awareness under the *Tech for Good* theme.
## ✨ Features
- 🧠 Predicts meteorite type using ML models  
- 🗺️ Interactive world map of meteorite landings  
- 📊 Exploratory data analysis of global trends  
- 🧾 Clean and simple dataset for reproducibility  
## 🛰️ Dataset
- **Source:** [NASA Open Data Portal — Meteorite Landings](https://data.nasa.gov/Space-Science/Meteorite-Landings/gh4g-9sfh)  
- **Attributes:** name, id, mass (g), recclass, year, reclat, reclong, fall type  
- Clean and reliable dataset for machine learning and geospatial visualization.
## ⚙️ Tech Stack
- **Languages:** Python  
- **Libraries:** pandas, numpy, scikit-learn, plotly, folium, streamlit  
- **Tools:** Jupyter Notebook / VS Code  
## 📈 Results
- Achieved high classification accuracy with Random Forest model  
- Identified major meteorite hotspots using geographic clustering  
- Demonstrated educational potential through interactive visual tools
